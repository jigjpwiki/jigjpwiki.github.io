# タレントの共通表示順
事務所マスター順を維持し、各事務所内で確認済みの所属開始日とデビュー日のうち遅い日（デビュー後加入なら加入日、所属後デビューならデビュー日）を使用。所属開始日がない場合、旧所属履歴がなければ年まで確認済みの公開個人デビュー記念日を暫定使用。移籍先の所属開始日が不明なら未確認。日付未確認は同事務所内の末尾に従来登録順、同日は登録順。旧所属・無所属・活動終了・所属不明の区分は維持。名前順・登録順の明示的な表示切り替えは維持。公開ビルドとAdminの候補・選択済みチップ・表示に共通ロジックを適用。マスターの並びや既存の関係IDを一括変更しない。Admin保存時に関係リストを表示順に整える。現在のデータは102名、所属開始日あり5名、年確定の公開デビュー記念日7件。日付補完は今回行わない。Admin本番Workerは再デプロイが必要。
