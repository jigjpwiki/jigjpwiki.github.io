# イベントUI v2.22.0
一覧は日付・曜日、登録済みイベント画像、開催区分・種類・タイトル・時刻・出演者・会場を1行で把握する構成。スマホは日付を左、画像と情報を右に配置。日付・月のみ、未確認は精度を維持。出演者は本体と出演枠の登録者を重複排除、名前リンクと共通AvatarStackを表示。開催中・今後・過去・日時未定の既存分類、JST、動的更新、検索、静的表示を維持。
詳細は画像・開催概要・公式告知を冒頭に集約。登録済み出演枠のみ時系列のタイムテーブルとして表示し、未定は末尾、同時刻は登録順。既存の動画視聴可否・配信先・料金・主催・所属を維持。現在の本番マスターの出演枠は0件なのでタイムテーブルを架空生成しない。
データ・Admin・API・音楽・グッズ・配信UIに変更なし。正式CIと実画面未確認。
