# グッズUI v2.24.0
販売企画・単独商品を既定ビューとし、商品単位の一覧を追加。商品は同一IDで一件、再販を含む全公開販売情報を集約。検索・販売方式・販売状況・タレント/所属フィルターを両ビューに適用。URL共有、静的HTML、既存の販売状態計算を維持。登録価格帯は確認済みの価格のみ、通貨を混ぜず未確認を明示。販売中・受付中の表示は購入可能性を保証しない。共通重ねアバター、企画・商品リンク、画像は切らず表示。現マスターに画像登録なしのためコンパクトな画像なし欄。画像の自動収集や推測なし。商品詳細は画像と販売条件を並べる。Admin・データ・API・他ページは変更なし。CIと実画面は未確認。
