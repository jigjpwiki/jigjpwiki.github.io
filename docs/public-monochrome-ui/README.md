# 公開UI：モノクロ・可読性優先

基準 v2.18.0 / 75ba0e14225fabaf8f6c3913b37356cc049cb96d。既存の配信スケジュールの見やすさを土台にする。ブランドのための装飾より、時刻・名前・タイトル・サムネイルを見つけやすいことを優先する。

## 設計
- ロゴを控えめなサイズに、ナビはアイコン＋文字、選択中は下線と太字。長いラベルが途中で折れないよう、狭い画面のみ短縮表記（アクセシブル名は維持）。
- 1100px以上は1段のヘッダー。小画面は6機能を常に表示し、動画表示スイッチ以外の補助操作をフッターに移す。
- 黒・白・無彩色の階層。状態を意味する色（配信中、配信プラットフォーム、曜日、記念日カテゴリ、販売中など）は残す。
- 既存の配信カード構造、データ取得・Swiper・動画表示・更新時刻・URL・Admin・マスターを維持。
- 新規外部依存なし。既存のUI回帰検証にヘッダー高さ、ラベル収まり、モノクロ文字、規約リンク、キーボード導線を追加。

実際の本番画面はユーザー提供のスクリーンショットを参考にした。新UIの実画面キャプチャは未取得。マージ前にCIと実表示を確認する。
