# 音楽・歌枠UI v2.21.0

- 歌動画：サムネイルをカード全面へ、公開日順、種別・曲名・原曲アーティスト・歌唱者・公開日・YouTubeリンクを整理。オリジナル楽曲の絞り込み直リンク。既存の種類、タレント・所属検索、URL、公開範囲を維持。
- 楽曲ライブラリ：曲名順、確認済みオリジナルMVのサムネイル（ジャケットとは呼ばない）、未登録は音符。歌唱者・歌動画・歌枠歌唱の掲載件数。同一人物は重複集計しない。楽曲詳細から同じ曲の動画・歌枠へ。
- 歌枠：トップの歌枠タブを6件限定から全件へ。歌唱者、日時、セットリストの確認状態、登録曲数。詳細ではトラック番号、楽曲、歌唱者、再生位置を分離。検証済み時間のみ時刻リンク。未確認・視聴不可の表示を維持。
- 複数歌唱者には既存の重ねアバターCSSをサーバー描画でも共用。5人まで、6人以上は4枚＋残数。名前へのリンクは維持。画像読み込み失敗時は頭文字。ホバー・タップ機能の追加なし。
- スキーマ・データ・Admin・API・共通ヘッダー・配信ページには変更なし。追加費用なし。
- 簡易レンダリングで凍結フィクスチャの歌動画4件、楽曲57件、歌枠17件、セットリスト31曲、485秒再生リンクを確認。正式Node/ブラウザーCIと実画面は未確認。次はイベント、記念日。グッズは保留。
