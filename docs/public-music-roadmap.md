# 公開UIの次段階

## v2.20.1 先行改修
歌動画の種類をオリジナル曲、歌ってみた、コラボ楽曲、その他の順にする。内部値 collaboration。複数歌唱者のオリジナル曲も存在するため人数での自動移行は行わず、既存レコードを保持し編集者が分類する。公開フィルター、カード、プロフィール、登録スキーマ、Adminの種類選択・表示を対応。Adminの本番Workerは別途デプロイが必要。追加APIや費用なし。

## 後続の改修順（今回の実装外）
1. 音楽・歌枠：曲名・原曲アーティスト・歌唱者・登録済み画像を中心に楽曲ライブラリを整理。歌動画・オリジナルの閲覧、歌枠のセットリスト、同一曲の歌唱履歴、既存の検証済みタイムスタンプ再生、複数歌唱者の重ねアバターを改善。画像未登録なら無理に補完しない。
2. イベント：予定と過去の区別、日付・開催状況・出演者の見やすさ、重ねアバター、詳細タイムテーブル。
3. 記念日：今日・直近の記念日一覧、カレンダーの視認性、誕生日・デビュー等の区別、プロフィールへの導線、モバイル対応。日本時間・既存の確認済み日付を維持。
4. グッズは後回し。

共通ヘッダーと配信カードは維持。大規模なAdmin改修は行わない。
