# タレント閲覧UI v2.20.0

## 設計
- 一覧：検索を最上段に独立、事務所・所属区分・グループ・活動状態・並び順を次段に配置。検索・複合条件・URL共有・戻る進む・IME対応は維持。表示中の所属セクションに移動できるリンクと人数を追加。カードはモノクロの余白、境界線、名前・アイコン・所属の階層を調整。
- プロフィール：名前・確認済み活動状態・所属・グループ・公式リンクを冒頭へ。グループは絞り込み済み一覧へ。重複した戻るリンクを省きパンくずを維持。存在する配信・記念日・音楽・イベント・グッズ・活動履歴へのページ内移動。活動履歴は初期表示。所属と活動状態を混同しない。
- 既存の静的HTML・配信取得・プラットフォーム色・共通ヘッダー・URL・データ・Adminは維持。外部依存なし。未確認の活動状態を推定しない。
