## デザインルール
既存ロゴと青系アクセントを維持。白い操作領域、薄いグレーの背景、境界線、8px基本角丸、最大1200pxの閲覧領域、可変ガター。1280px以上は横並び、狭い画面では全ナビを2段表示（760px以下）。文字ラベルとSVGを併記し、JSを必要としない。本文スキップリンク、フォーカス、現在位置を維持。通常閲覧ページと規約のフッターを統一し、配信画面の更新時刻フッターは維持。

## 検証計画
既存ブラウザーテストに320/390/768/1440px、JS有効/無効、全主要画面のヘッダー領域・リンクの可視性・本文移動・フッターを追加。既存の配信カード、Swiper、公開URL、絞り込み、マスター検証は維持。新規外部依存・API・有料サービスなし。

実際の本番画面のスクリーンショットは取得できていないため、現状評価はソースと過去の検証記録に基づく。最新CIと実画面の確認はマージ前の検証項目。今後は共通ナビを土台として、配信・タレント・音楽・イベント/記念日・グッズの固有UXを個別PRで進める。
