# 配信コラボ候補表示 v2.19.0

- 配信主はアカウントID、未登録の場合は収集設定の一意な完全一致名から特定。主が特定できない場合は表示しない。
- タイトルは登録済み表示名・別名（短すぎる名前や同名は除く）の完全文字列一致。長い登録名内の短い名前は除外。NFKC・大小文字正規化。部分的な読み・推測なし。
- 概要は参加者/コラボ相手などの明示された区画を優先。登録済みYouTube/X/Twitch/TikTokのアカウントURLと名前を照合。宣伝・クレジットなどを除外。タイトルにコラボの明示があるときだけ、区画外の同一行にある一致した名前とURLも候補にする。
- YouTubeの既存videos.list応答、Twitchアーカイブの既存説明を利用。API追加なし。全文保存せずIDのみ。ビルド時に公開可能なタレントに絞り、ID・名前・プロフィール画像を投影。古い収集データはタイトルのみ。
- UIは主配信者名の右、サムネ左。モバイルは名前の下・タイトルの上。5人まで5枚、6人以上4枚＋残り。画像がない場合は頭文字。追加のホバー・タップなし。スクリーンリーダー用の名前のみ。共通 AvatarStack を他ページに再利用可能。
- 参加は推定であり、タイトルで言及しただけのケースは残り得る。外部タレント・短名・曖昧な区画・概要のないライブは取りこぼすことがある。ユーザーのプロトタイプを参考にしたが実機の見え方・判定結果はCIと実運用で要確認。
